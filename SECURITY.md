# Security Policy

## Supported versions

The latest released version receives security updates.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, email **[support@viprasol.com](mailto:support@viprasol.com)** with details
and steps to reproduce. We will acknowledge your report within 5 business days and
keep you informed as we work on a fix.

Thank you for helping keep Viprasol Tech projects and their users safe.
